# Risk questions: frontend (starter list, not measured yet)

1. **States**: what does the user see while loading, on an empty result, and on an error?
2. **Network**: what happens when a request fails, is slow, or answers twice (double submit)?
3. **Access**: what does a user without permission see, and what is hidden versus disabled?
4. **Existing data**: what happens to saved state, URLs and cached data from before this change?
5. **Accessibility**: can it be used with the keyboard and a screen reader?
6. **Scope**: what does this feature leave out on purpose?
