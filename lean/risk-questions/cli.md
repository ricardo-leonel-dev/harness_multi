# Risk questions: CLI / script (starter list, not measured yet)

1. **Input**: what happens with missing, empty, malformed or unexpected arguments and files?
2. **Re-runs**: what happens when it runs twice, or after a run that stopped halfway?
3. **Side effects**: what does it write or delete, and can a mistake be undone?
4. **Environment**: what does it assume about the shell, paths, tools and permissions?
5. **Scope**: what does this feature leave out on purpose?
